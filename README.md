# hxyfront-62011 马术蹄铁修整档案

源提示词编号：6

做一个面向马术俱乐部蹄铁师的修蹄记录前端项目，可以记录马匹编号、步态问题、蹄形评估、蹄铁类型、钉位、修蹄日期、下次复查日期和照片备注。页面需要有马匹列表、复查提醒、左右前后蹄对比记录、异常步态标记和蹄铁更换历史。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62011

## 功能

- **录入工作台**：选择/新建马匹 → 选四蹄（左前/右前/左后/右后）→ 填修蹄日期、复查日期、蹄形、步态、蹄铁、钉位、备注和照片，保存后立即出现在该马档案。
- **按马匹 + 四蹄归档**：每匹马的"四蹄总览/单蹄"时间线，蹄铁更换历史单独列出；所有旧记录（含旧照片）只追加、不覆盖。
- **同日同蹄拦截**：同一天同一蹄再次保存时阻止并提示先查看已有记录，可一键跳到该记录。
- **日期校验**：复查日期早于修蹄日期时不保存，表单已填内容原样保留并就地提示。
- **首页复查提醒**：按复查日期升序排列，逾期整卡/整行标红、今日复查标黄。
- **快捷筛选**：步态异常、30 天内换过蹄铁、复查逾期，可多选组合。
- **数据持久化**：记录保存在浏览器 localStorage；照片在上传时自动压缩为 JPEG。
