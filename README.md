# hxyfront-62011 马术蹄铁修整档案

面向马术俱乐部蹄铁师的修蹄记录工作台。录入即按马匹与左右前后蹄归档，照片和换铁历史只追加、不覆盖。

## 功能

- **持续录入工作台**：弹窗录入马匹编号、马名、状态、蹄位（左前/右前/左后/右后）、修蹄日期、蹄形评估、步态、蹄铁类型、钉位、是否换铁、下次复查日期、备注与照片；保存后立即出现在该马档案并高亮定位。
- **四蹄归档对比**：每匹马按左前、右前、左后、右后四个独立时间线展示，新→旧排列；旧照片与历史记录不会被新记录覆盖或删除。
- **同日同蹄防重复**：同一匹马、同一天、同一蹄再次保存时，先展示已有记录并要求确认；可“去看已有记录”，或确属当天第二次修整时强制追加。
- **复查日期校验**：下次复查早于修蹄日期时拒绝保存并提示，已填写的全部内容原样保留。
- **首页复查提醒**：按下次复查日期排序，逾期整行标红、当天/3 天内黄色提示；指标卡显示逾期与待复查数量。
- **快捷筛选**：逾期复查、近期复查、步态异常、30 天内换蹄铁、运动马/休养马、前蹄/后蹄有记录。
- **数据持久化**：记录存于浏览器 localStorage；上传照片自动压缩（最长边 900、JPEG），刷新不丢。

首次打开内置 3 匹示例马（含逾期复查、异常步态、近期换铁），录入自己的马后全部以本地数据为准。

## 技术栈

React 19 + Vite + TypeScript，无后端，localStorage 持久化。

## 本地运行

```bash

npm run dev
```
